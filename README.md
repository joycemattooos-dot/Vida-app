# VIDA

Primeira versão demonstrativa do aplicativo VIDA em Next.js.

## Rodar localmente

`npm install` e `npm run dev`.

## Importante

Esta versão contém apenas a interface inicial e navegação entre módulos. Não há autenticação, sincronização, armazenamento de dados, cálculos nutricionais nem timers funcionais ainda. O projeto Supabase é separado do MONEY e será integrado em uma próxima etapa.
